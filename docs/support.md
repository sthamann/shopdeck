# Shopdeck support

Shopdeck manages your own Shopware 6 shops on macOS 14 or later. The current distributed binary targets Apple silicon.

For setup, see the [README](../README.md) and [AI guide](ai-guide.md). Report a bug or request a feature in [GitHub Issues](https://github.com/sthamann/shopdeck/issues).

A useful bug report includes your Shopdeck version, macOS version, the affected screen and steps to reproduce the issue. Use demo or anonymized data for screenshots. Never post integration secrets, access tokens, customer records or private order documents.

If a shop cannot connect, check that its URL is reachable, its Admin API integration is active and the requested permissions are granted. Revoke credentials in the Shopware administration if a secret has been exposed.

For privacy information, read the [privacy policy](privacy.md).
